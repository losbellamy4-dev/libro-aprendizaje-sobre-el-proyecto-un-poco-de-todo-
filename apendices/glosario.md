# Apéndice A — Glosario

> El glosario **crece con cada capítulo**. Cada término indica el capítulo donde se define.
> Los términos marcados con **[AVANCE]** se han mencionado, pero se definen con rigor más adelante.
> Orden alfabético.

| Término | Significado | Capítulo |
|---|---|---|
| **Anteperiodo** | En un decimal periódico mixto, cifras decimales que hay entre la coma y el periodo y que no se repiten. En 0,41(6), el anteperiodo es 41. | 1.1 |
| **Aproximación** | Número que se usa en lugar de otro porque está cerca de él, pero no es igual. Se escribe con ≈: π ≈ 3,14. | 1.1 |
| **Cerrado (conjunto cerrado para una operación)** | Un conjunto A es cerrado para una operación si, operando dos elementos cualesquiera de A, el resultado siempre está en A. ℕ es cerrado para la suma, pero no para la resta. | 1.1 |
| **Conjetura** | Afirmación que parece verdadera (por ejemplos o por evidencia computacional) pero que no está demostrada. | 1.1 |
| **Conjunto** | Colección de objetos (elementos) en la que está claro qué objetos pertenecen y cuáles no. | 1.1 (formal en 11.1) |
| **Contraejemplo** | Caso concreto que demuestra que una afirmación del tipo «para todo…» es falsa. Uno solo basta. | 1.1 |
| **Cota** | Valor máximo (cota superior) o mínimo (cota inferior) que se sabe que una cantidad no puede sobrepasar. No garantiza que se alcance. | 1.1 |
| **Cuadrado perfecto** | Número natural que es el cuadrado de otro natural: 0, 1, 4, 9, 16, 25, … | 1.1 |
| **Decimal exacto** | Expresión decimal con un número finito de cifras: 0,175. | 1.1 |
| **Decimal periódico puro / mixto** | Decimal infinito en el que un bloque de cifras (periodo) se repite indefinidamente, justo después de la coma (puro: 0,(36)) o tras un anteperiodo (mixto: 0,41(6)). | 1.1 |
| **Demostración** | Razonamiento que prueba que una afirmación es verdadera en **todos** los casos a los que se refiere. | 1.1 (formal en Módulo 10) |
| **Densidad (de ℚ)** | Propiedad de que entre dos racionales distintos siempre hay otro racional. | 1.1 |
| **Elemento** | Cada uno de los objetos que forman un conjunto. «x ∈ A» significa que x es elemento de A. | 1.1 |
| **Entero (número)** | …, −2, −1, 0, 1, 2, … Conjunto ℤ. | 1.1 |
| **Evidencia computacional** | Comprobación por ordenador en un número finito de casos. Apoya una afirmación, pero no la demuestra (salvo que cubra todos los casos posibles). | 1.1 |
| **`float`** | Tipo de número decimal aproximado que usan los ordenadores (coma flotante). No es exacto: en Python `0.1 + 0.2 == 0.3` da `False`. | 1.1 (a fondo en 6.2 y 8.7) |
| **Fracción generatriz** | Fracción irreducible que da un decimal exacto o periódico dado. La de 0,41(6) es 5/12. | 1.1 |
| **Fracción irreducible** | Fracción cuyo numerador y denominador no tienen divisores comunes mayores que 1. | 1.1 |
| **Fracciones equivalentes** | Fracciones que representan el mismo número: a/b = c/d cuando a·d = b·c. | 1.1 |
| **GF(7)** **[AVANCE]** | Campo finito de 7 elementos: el conjunto {0, 1, 2, 3, 4, 5, 6} con la suma y el producto «con reloj de 7» (restos de dividir entre 7). | 1.1 (definición formal en 13.3) |
| **Irracional (número)** | Número real que no se puede escribir como fracción de enteros. Su expresión decimal es infinita y no periódica: √2, π. Conjunto: 𝕀 = ℝ ∖ ℚ. | 1.1 |
| **Natural (número)** | 0, 1, 2, 3, … Conjunto ℕ. En este libro, 0 ∈ ℕ. | 1.1 |
| **Opuesto** | El opuesto de a es −a, el número que sumado con a da 0. | 1.1 |
| **Orden (a < b)** | a < b significa que b − a es positivo; en la recta, a está a la izquierda de b. | 1.1 |
| **Parte entera** | En una expresión decimal, la parte anterior a la coma. (Las funciones ⌊x⌋ y ⌈x⌉ se definen en 1.4.) | 1.1 |
| **Periodo** | Bloque de cifras que se repite indefinidamente en un decimal periódico. | 1.1 |
| **Primo (número)** | Natural mayor que 1 cuyos únicos divisores son 1 y él mismo. | 1.1 (a fondo en 2.2) |
| **Principio del palomar** **[AVANCE]** | Si se reparten más objetos que cajones, algún cajón recibe al menos dos objetos. | 1.1 (formal en 11.6) |
| **Racional (número)** | Número que se puede escribir como a/b con a, b enteros y b ≠ 0. Conjunto ℚ. | 1.1 |
| **Real (número)** | Número que se puede escribir con una expresión decimal (finita o infinita). Corresponde a un punto de la recta numérica. Conjunto ℝ. | 1.1 |
| **Recta numérica (recta real)** | Recta en la que cada punto corresponde a un número real y viceversa. | 1.1 |
| **Reducción al absurdo** **[AVANCE]** | Método de demostración: se supone lo contrario de lo que se quiere probar y se llega a una contradicción. | 1.1 (formal en 10.7) |
| **Resto** | En la división de a entre b, lo que «sobra»: a = cociente · b + resto, con 0 ≤ resto < b. | 1.1 (formal en 2.5) |
| **Subconjunto (A ⊂ B)** | A es subconjunto de B si todo elemento de A es también elemento de B. | 1.1 |
