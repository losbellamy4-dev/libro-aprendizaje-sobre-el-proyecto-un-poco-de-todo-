# Apéndice B — Hoja de fórmulas

> Crece con cada capítulo. Cada fórmula indica sus **condiciones** (cuándo se puede usar) y su
> **estado** (demostrada, pendiente o definición). Una fórmula usada fuera de sus condiciones es
> una de las fuentes de error más frecuentes.

## Capítulo 1.1 — Conjuntos de números

| Código | Fórmula | Condiciones | Estado |
|---|---|---|---|
| F1 | ℚ = { a/b : a, b ∈ ℤ, b ≠ 0 } | — | Definición |

| F2 | a/b = c/d ⟺ a·d = b·c | b ≠ 0, d ≠ 0 | Propiedad |

| F4 | (a/b)·(c/d) = (a·c)/(b·d) | b ≠ 0, d ≠ 0 | Propiedad |
| F5 | (a/b) : (c/d) = (a·d)/(b·c) | b ≠ 0, c ≠ 0, d ≠ 0 | Propiedad |
| F6 | a/b < c/d ⟺ a·d < c·b | **b > 0, d > 0** | Propiedad |
| F7 | a < (a + b)/2 < b | a < b | Demostrada (Prop. 1.3) |
| F8 | Decimal exacto con m cifras decimales = N/10^m (N: el número sin la coma) | — | Demostrada (Prop. 1.6) |

| F10 | Longitud del periodo de a/b ≤ b − 1 | b > 0 entero | Demostrada (Prop. 1.4) |
